# Demo Guide (about 3 minutes)

Open `/demo` for one-click launch cards and **RESET DEMO** (deletes everything this demo session saved and starts a new session). No sign-in is required.

1. **Landing `/`**: move the mouse (camera, particles and core react), click a node to see its details, then **ENTER THE LAB**.
2. **GameZero** (the showpiece): make 2–3 moves on the board, press *Let the AI learn*. Point out the "Hypothesis rejected" entries and the shrinking hypothesis count. Press *Play to win*.
3. **Trust Without Identity**: enter an adult date of birth and press *Prove age ≥ 18*. Show the Revealed vs Hidden ledger. Then pick *Try to cheat* with an underage date and show the verifier rejecting it.
4. **EXPIRY**: issue the default ₹1000 (Food, Student, ₹500 cap, 48 h). Try ₹300 food (approved), ₹700 electronics (rejected), then ₹500 food after expiry (rejected). Edit the rules live.
5. **Blood**: *Load emergency example*, run matching, hover the network nodes and read each donor's reasons.
6. **Object / 100 Lives** and **Nutrition**: need AI keys. Pick an example chip and run; click branches of the life tree.
7. **/architecture**: show the fallback chain and the live router status.

Each page ends with Impact and the relevant SDG mapping.

Tip: if AI keys are not set yet, steps 2–5 still demonstrate fully.
